## 3. Subsystem Deep-Dives

### 3.1 `discord_rpc` (`RPCIPC.js`, `RPCWebSocket.js`, `safeEmitter.js`)
- **Named Pipe Discovery (`RPCIPC.js`)**:
  - On `win32`, `socketBasePath` is `'\\\\?\\pipe\\discord-ipc'`.
  - Probes `${socketBasePath}-${tries}` from `0` to `9` (`\\?\pipe\discord-ipc-0` .. `\\?\pipe\discord-ipc-9`) via `net.connect(socketPath)`: if connection succeeds, the slot is occupied; if `connect` errors out, the slot is selected.
- **Object-Capability Membrane (`safeEmitter.js` & `RPCWebSocket.js`)**:
  - Never returns raw Node `net.Server`, `net.Socket`, `http.Server`, `http.IncomingMessage`, or `ws.WebSocket` instances to the renderer.
  - Wraps events in `createSafeEmitter()` (`Object.create(null)`, `maxListeners = 10`, `fn.apply(null, args)` stripping `this`) and stores underlying `http.Server` / `ws.Server` instances inside a closure-private `origInstanceMap` keyed by integer `instanceId`.

### 3.2 `discord_overlay2` & `discord_hook`
- **Offscreen Renderer (`discord_overlay2\host.js`)**:
  - Creates an offscreen `BrowserWindow` (`offscreen: { deviceScaleFactor }`, `nodeIntegration: false`, `sandbox: false`, `contextIsolation: true`, `preload: require.resolve('./overlayPreload')`).
  - Performs a two-stage handshake via `file://${__dirname}/start.html?pid=${pid}` (`renderer_started` + `first_framebuffer`) before navigating to `overlayURL`.
  - Streams painted bitmaps (`image.getBitmap()`) to `overlay.sendFramebuffer(pid, ...)` and translates game input via `overlay.translateInputEvent(event)` -> `webContents.sendInputEvent(inputEvent)`.
- **URL Protocol Denylist (`discord_overlay2\securityUtils.js`)**:
  - Blocks 14 dangerous schemes (`file:`, `javascript:`, `vbscript:`, `data:`, `about:`, `chrome:`, `ms-cxh:`, `ms-cxh-full:`, `ms-word:`, `shell:`, `ms-msdt:`, `search-ms:`, `ms-officecmd:`, `ms-appinstaller:`) and rejects single-letter schemes (`MIN_URL_SCHEME_LENGTH = 2`) to block Windows drive-letter paths (`C:\...`) in `shell.openExternal()`.

### 3.3 `discord_voice` & `discord_krisp`
- **Dave / Messaging Layer Security (MLS) E2EE (`discord_voice\index.js`)**:
  - Binds 9 E2EE methods onto `VoiceConnection`: `prepareSecureFramesTransition`, `prepareSecureFramesEpoch`, `executeSecureFramesTransition`, `getMLSKeyPackage`, `updateMLSExternalSender`, `processMLSProposals`, `prepareMLSCommitTransition`, `processMLSWelcome`, `getMLSPairwiseFingerprint`.
- **AI Noise Cancellation & Background Segmentation**:
  - Links `discord_krisp` (5 `.kef` models totaling 27.3 MB) via `VoiceEngine.setKrispModelDirectory` and bundles `mediapipe.dll` (8.68 MB) + 2 `.tflite` selfie segmentation models.

### 3.4 `discord_utils` Anti-Keylogging Hardening
- **Global Input Watcher Stripping (`discord_utils\index.js:90-91`)**:
  - Passes `nativeUtils.inputWatchAll` to `initInputCapture(nativeUtils.inputWatchAll)` and immediately executes `delete nativeUtils.inputWatchAll;` before exporting `module.exports`.
- **Single-Character Global Keybind Cap (`discord_utils\input_event.js:49-53`)**:
  - Enforces `MAX_SINGLE_CHARACTER_BINDS = 8` for scan codes `65..90` (A–Z single keys without modifiers) on `win32`, preventing compromised renderer scripts from registering 26 global keybinds to act as an out-of-focus keylogger.
